# CycloneDX cryptography registry

`cryptography-defs.json` is CycloneDX's registry of cryptographic algorithm families and elliptic curves, unchanged,
from the CycloneDX 1.7.2 release (https://github.com/CycloneDX/specification/tree/1.7.2/schema), under the Apache
License 2.0. `--cbom` uses it to name each algorithm's family and primitive the way CycloneDX does.
